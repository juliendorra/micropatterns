Provision a Device

Send WiFi networks and your User ID to an M5Paper or Watchy over Bluetooth

The user ID and the WiFi networks are written independently. Tick only what you want to change: anything left unticked is not touched on the device.

Rotating the ID on its own is the fix for an ID that leaked: tick this, untick the networks below, and the stored WiFi passwords are left exactly as they are.

The list below replaces the one on the device, and networks are tried in this order, so put the one you are usually on first. Names and their order are remembered in this browser; passwords are not stored here and are never read back from the device. A blank password means "keep whatever the device already has for that name" — each row says which way it will be read. To clear the device entirely, use "Forget credentials".
