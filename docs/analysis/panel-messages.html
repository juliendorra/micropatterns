Every word these two screens can say

The Watchy (200×200) and the M5Paper (540×960) now draw from one message vocabulary. Below: every text frame either device can show, laid out with the real font metrics, wrap rule and y-offsets from the firmware.

Watchy — 200×200, shown 1:1

Title and body are both text size 2: a 6×8 glyph scaled ×2, so 12 px per glyph and 16 glyphs per line. Body text used to be size 1 and was unreadable on a panel this small. Lines wrap on the last space that fits; a single word longer than a line is hard-cut.

M5Paper — 540×960, shown at one third

Text size 3 on the same 6×8 font: 18 px per glyph, 30 glyphs per line, and no wrapping — each call draws one centred line at a fixed y. Messages appear over whatever the script left on the panel, which is why they are short.

The shared vocabulary

One header, mp_messages.h, compiled by both firmwares. Sync outcomes travel in ScriptSyncResult::message, so a sync reports itself in the same words on either device.
